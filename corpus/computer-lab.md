# Computer lab

The lab is shared by every class, so it must be left ready for the next lesson.

## Checklist before a lesson

Switch on the computers ten minutes before the class arrives, because the first sign-in and updates take time. Check that the projector shows the teacher's screen.

Make sure the software for the lesson opens on every machine, and put a sign on any computer that is out of order so learners do not waste time on it.

## A computer will not start

Check that the power cable and the wall switch are on and the monitor is connected. If the computer starts but shows a black screen, check the monitor input button.

If it beeps or restarts again and again, switch it off, label it with the date and the problem, and report it in the fault log. Do not open the case during lesson time.

## Installing software

Only the IT office installs software on lab computers. Teachers who need a program for a lesson should request it at least one week ahead.

We use free and licensed software only. Install it on one computer first and test it, then roll it out to the rest of the lab after school.

## Viruses and USB drives

Learners should not plug personal USB drives into lab computers. Files are shared through Google Classroom instead.

If a computer shows strange pop-ups or files with odd names, disconnect it from the network, run a full antivirus scan and report it. Keep antivirus definitions updated automatically every day.
