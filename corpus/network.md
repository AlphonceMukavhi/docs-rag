# Wi-Fi and network

The school has two wireless networks. Staff Wi-Fi is for school laptops and office devices. Guest Wi-Fi is for visitors and personal phones and cannot reach the printers or shared drives.

## Connecting a device to staff Wi-Fi

Only school-owned devices go on staff Wi-Fi. Ask the IT office for the password; it is never written on the board or shared in group chats.

Select the staff network, enter the password and confirm the device gets an address. If a personal phone needs internet, use the guest network instead.

## Connected to Wi-Fi but no internet

If the device shows Wi-Fi bars but pages do not load, check whether other devices in the same room have the same problem. If everyone is affected, the problem is the internet link, not the laptop.

If only one device is affected, forget the network and join it again, then restart the device. Check that the date and time are correct, because a wrong clock breaks secure websites.

## Slow internet in the computer lab

When a whole class goes online at once, the connection is shared between thirty computers. Large downloads and automatic updates slow everyone down.

Schedule Windows updates for after school hours, and ask learners to close video sites that are not part of the lesson. If the lab is still slow, test the speed from one computer while the others are off to see the real line speed.

## Restarting the router and access points

Restart network equipment only after school or during a break, because everyone loses connection for several minutes.

Switch off the access points first, then the router. Wait one minute, switch the router on, wait until its internet light is steady, then switch the access points on. Record the restart and the reason in the network log.
