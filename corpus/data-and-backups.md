# Data and backups

School data includes learner records, results, fees records and staff files. Losing it or leaking it hurts real families, so it is handled carefully.

## What is backed up and when

Shared Drive folders are stored by Google and kept for thirty days after deletion. The office computer that runs the accounting package is backed up every Friday to an external drive.

A second copy of the weekly backup is kept off site. Test a restore once a term: a backup that has never been restored is only a hope.

## Restoring a deleted file

If a file was deleted from Google Drive in the last thirty days, open Drive, go to Bin, right-click the file and choose Restore.

If it was deleted from a shared drive by someone else, the shared drive manager can restore it. After thirty days, an administrator may still recover it from the Admin console for a short period.

## Keeping learner records private

Learner records are shared only with staff who need them. Never send results or medical notes to a personal email address or a WhatsApp group.

Share files with named people instead of using "anyone with the link". Lock the screen when you leave a computer, even for a minute.

## Results spreadsheets

Each class has one results spreadsheet created from the school template. Do not change column names or add merged cells, because the reports and dashboards read those columns.

Enter marks as numbers only. Comments go in the comments column, not in the mark cells, so averages and charts calculate correctly.
